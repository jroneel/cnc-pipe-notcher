01 / Model & stock

Input and display units can be switched. Model coordinates and exported G-code stay in millimetres.

Upload a model to detect tubing shape and dimensions.

Detected for rounded square/rectangular tubing. Zero means sharp corners. Automatic mode measures inner and outer radii independently. Manual mode assumes an inner radius of outer radius minus wall thickness, or zero if smaller.

02 / Cutting & bevel

Holes are cut first, then the ends with the chuck-side cut last. End lead-ins require extra blank stock beyond the modeled ends. Pierce settings require machine calibration.

End cuts use the selected signed B tilt; holes use B0. B tilts the torch toward +X for positive angles. Bevel is relative to the radial direction; it does not follow the local notch normal. The machine preview includes B tilt and pivot compensation; enter the measured pivot-to-tip distance for bevels.

Z is the pivot distance from the tube centre. Enter the measured arm length; bevel export requires a nonzero value.

Prusa export shows the selected holes and ends as simulated extrusions on an unwrapped tube surface. It is not a 3D tube or rotary machine simulation. Do not run it on a printer or CNC machine.

The XYZ viewer file draws the selected hole and end contours with standard XYZ moves for third-party viewers. It is for viewing only and must not run on the notcher. Only the contours selected by the cutting scope are included. Bevel material removal is not simulated.

Preview first. Machine export supports axial/radial B bevels on configured grblHAL. Never run an unverified program on a machine.

    Machine assumptions

    X follows the tube; A rotates it about X; B tilts the torch toward X. Z positions the tilt pivot above the tube centre, including radial stock height and pivot compensation. No Y axis is used. A zero corresponds to the model's +Y surface at the head. Output uses inverse-time feed to coordinate millimetres and degrees.

    Closed through-hole outlines and both ends are supported on constant-section tubing. Paths reproduce outer outlines with a radial torch; wall-normal bore shape on rectangular faces may differ. Blind pockets, kerf compensation, fixture collision checking and arbitrary bevel orientation remain unsupported.
